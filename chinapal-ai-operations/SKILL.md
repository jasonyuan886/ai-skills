# chinapal-ai-operations

## 适用场景

1. AI聚合平台从0到1搭建与运营
2. 出海网站SEO内容策划与优化
3. 技术博客矩阵搭建（Medium + Dev.to）
4. 博主/KOL合作外联与报价管理
5. 流量获取策略规划与执行
6. AI产品技术功能迭代开发

## 执行步骤

### 一、AI聚合平台运营模式

#### 1.1 平台定位与品牌升级

- **品牌统一**：全站统一品牌名称、Logo、色调，确保中英文一致
- **信任要素修复**：补充 About Us、Privacy Policy、Terms of Service、Contact 等页面
- **翻译质量**：全站多语言翻译必须人工审核，禁止机翻直出
- **评分体系**：建立分身/助手评分机制，目标从低分逐步提升至8+

#### 1.2 分身/助手体系管理

- **角色感知**：每个AI助手有明确的角色定义、专长领域、对话风格
- **分级管理**：按优先级P0/P1/P2分级，P0为核心必备助手，P1为重点推荐
- **示例配置**：
  - P0（6个）：核心通用助手，覆盖翻译、聊天、写作等高频场景
  - P1（7个）：垂直领域助手，覆盖特定行业/功能需求
- **显示修复**：确保聊天界面正确显示分身信息（头像、名称、描述）

#### 1.3 技术功能迭代

- **Web Speech API**：集成浏览器原生语音识别实现语音翻译功能
- **翻译页优化**：添加一键清空按钮，提升用户体验
- **PROJECT_STATE 7段式持久化**：
  1. 状态定义（State Schema）
  2. 状态存储（LocalStorage/IndexedDB）
  3. 状态恢复（页面刷新自动还原）
  4. 状态同步（多标签页同步）
  5. 状态迁移（版本升级兼容）
  6. 状态备份（导出/导入）
  7. 状态清理（过期数据自动清除）
- **埋点追踪**：修复事件追踪路径，确保用户行为数据可采集分析

### 二、SEO内容创作策略

#### 2.1 SEO页面规划

- **核心SEO页**（6篇）：围绕平台核心功能关键词
  - 选题原则：搜索量适中、竞争度可控、与产品强相关
  - 结构：H1主标题 + H2分段 + FAQ Schema + 内链锚文本
  - 每篇1500-3000词，包含产品CTA

- **工具页**（2篇）：提供实用工具吸引自然流量
  - 选型：与AI产品相关的在线小工具（如AI费用计算器、模型对比工具）
  - 目标：工具本身有使用价值，同时自然引导至平台注册

#### 2.2 博客内容矩阵

**Medium 策略**：
- **主题定位**：中国名字（Chinese Names）等文化话题，吸引对中国文化感兴趣的海外用户
- **发布频率**：每篇独立成文，主题间有内在关联
- **写作风格**：文化解读 + 实用信息 + 品牌软植入
- **目标**：每篇带来稳定长尾流量

**Dev.to 策略**：
- **定位**：技术开发者社区，分享AI/技术实践
- **累积策略**：持续发布积累至40+篇建立权威性
- **内容方向**：AI工具测评、技术实现分享、开发者指南
- **互动**：参与社区讨论，回复评论建立影响力

#### 2.3 SEO技术规范

- 页面必须有完整的 meta title / description / og tags
- 使用 Schema.org 结构化数据（FAQ、HowTo、Product）
- 图片必须有 alt 标签，使用描述性文件名
- 内链策略：每篇文章至少3个指向产品页的内链
- 页面加载速度 < 3秒（Core Web Vitals达标）

### 三、博主合作外联流程

#### 3.1 博主筛选标准

- **领域匹配**：旅游/科技/AI/生活类博主
- **受众匹配**：目标市场用户画像一致
- **粉丝量级**：中小型博主优先（1K-100K粉丝），性价比高
- **互动率**：评论/点赞比例合理，非纯刷量

#### 3.2 外联流程

1. **名单建立**：按平台（YouTube/Instagram/TikTok/Blog）分类整理
2. **背景调查**：检查博主历史合作品牌、内容风格、受众画像
3. **报价模板**：
   - 明确合作形式（视频/图文/Stories）
   - 报价包含：内容制作费 + 发布费 + 授权期
   - 提供阶梯报价（1篇/3篇/长期合作）
4. **外联邮件**：
   - 标题：简洁明了，突出合作价值
   - 正文：品牌介绍 + 合作意向 + 为什么选TA + 预期效果
   - 附件：品牌资料包（Media Kit）
5. **跟进节奏**：首次外联 → 3天后跟进 → 7天后最终跟进

#### 3.3 合作管理

- **已外联**：记录外联时间、博主信息、联系方式
- **已送达报价**：跟踪报价状态，记录回复
- **谈判中**：记录议价过程、最终价格
- **已完成**：保存合作内容链接、效果数据
- **长期维护**：合作后保持关系，为后续合作铺路

### 四、流量获取策略

#### 4.1 自有可控流量路径（核心4条）

1. **SEO自然流量**：通过Google/Bing搜索获取
   - 关键词布局 + 内容持续更新 + 技术SEO优化
   
2. **技术博客引流**：Medium/Dev.to等开发者社区
   - 高质量技术文章 + 个人主页链接 + 社区互动

3. **社媒矩阵**：LinkedIn/Twitter/Telegram
   - 行业内容分享 + 产品动态 + 用户案例

4. **博主合作**：付费/免费合作获取曝光
   - 精准选博主 + 优质内容 + 长期关系

#### 4.2 高风险渠道关停原则

- **关停标准**：投入产出比低、存在封号/处罚风险、流量质量差
- **替代方案**：将资源转移到自有可控渠道
- **定期评估**：每月复盘各渠道ROI，动态调整

### 五、运营数据复盘

#### 5.1 关键指标

- **流量指标**：UV/PV、来源分布、跳出率、停留时间
- **转化指标**：注册转化率、付费转化率、LTV
- **内容指标**：文章阅读量、分享数、外链数
- **博主指标**：外联响应率、合作完成率、ROI

#### 5.2 复盘节奏

- **周复盘**：流量变化、内容发布进度、博主外联进展
- **月复盘**：转化数据、渠道ROI、策略调整
- **季复盘**：整体增长趋势、资源重新分配

## 关键经验总结

1. **品牌统一是基础**：全站品牌、翻译、信任要素必须一步到位，否则用户信任度极低
2. **评分是信任锚点**：AI助手评分从2.8到8.12，需要持续优化回答质量
3. **SEO是长期资产**：每篇SEO文章都是长期流量入口，质量 > 数量
4. **博主合作要精准**：不贪多，选对博主比数量更重要
5. **流量要可控**：依赖平台算法不如建自有流量路径
6. **技术体验决定留存**：功能bug会直接导致用户流失，技术债要及时还
7. **数据驱动决策**：所有策略调整都要有数据支撑，不凭感觉

## 注意事项

- 所有对外内容禁止使用"Coze"等内部品牌名，统一使用自有品牌
- 博主合作前必须做背景调查，排除竞争对手和不当内容创作者
- SEO页面发布后必须验证Google收录状态
- 技术功能上线前必须完成端到端测试
- 外联邮件发送需遵守各平台反垃圾邮件规范
