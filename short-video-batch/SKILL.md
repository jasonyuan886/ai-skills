# short-video-batch

## name
short-video-batch

## description
短视频批量制作与多平台发布技能。覆盖YouTube Shorts、Pinterest Video Pin、TikTok等平台的竖版短视频全流程制作，包括选题策划、AI素材生成、Ken Burns动效制作、音频配音、字幕叠加、多平台规格适配、批量发布管理。基于真实发布经验：YouTube 8条视频全部公开发布、Pinterest每日双站（EN/JP）发布、赵家驹热点短视频10条批量交付（总成本仅¥9）、ChinaPal TikTok视频制作。核心能力：即梦生成素材→剪映二次编辑（加字幕/BGM/转场/AI声明）→多平台发布的完整SOP。

## 触发条件
当用户需要以下场景时触发本技能：
- 批量制作短视频（2条以上）
- 制作YouTube Shorts / TikTok / Pinterest视频
- Ken Burns动效视频制作
- 热点追踪快速出视频
- 视频多平台适配与发布
- 视频制作成本优化
- 视频SOP流程执行

## 执行流程

### 第一步：选题策划

#### 1.1 选题来源
- **痛点共鸣型**：用户日常痛点切入（如"I HATE My Countertop Vacuum Sealer"），适合FreshLock产品推广
- **热点追踪型**：追踪社媒热点话题快速制作（如赵家驹热点10条），时效性24-48h内出片
- **文化反差型**：中式文化vs西方视角（如中元节、高铁点餐、小费文化），适合海外传播
- **产品展示型**：产品功能演示、Before/After对比，适合TikTok和YouTube Shorts
- **情感向**：节日情感内容（中秋、国庆），适合YouTube长视频和Shorts混合

#### 1.2 选题评估标准
- 目标平台匹配度（竖版优先）
- 制作成本（优先低成本方案）
- 时效性窗口（热点类48h内必须发布）
- 素材可复用性（一次拍摄多平台分发）
- CTA植入自然度（引导访问独立站或关注账号）

#### 1.3 批量选题规划
- 每批次建议5-10条，主题间保持风格统一
- 优先级：热点类 > 痛点类 > 展示类 > 情感类
- 同一素材拆分为多条视频（不同角度/文案）

### 第二步：素材准备

#### 2.1 脚本撰写
```
脚本结构（30-60秒短视频）：
├── 钩子（0-3秒）：争议性/悬念性开场，抓住注意力
├── 冲突展开（3-15秒）：痛点/问题/反差
├── 解决方案（15-40秒）：产品/方案/文化解读
├── CTA收尾（最后3-5秒）：自然引导，不硬广
└── 总时长控制：YouTube Shorts ≤59秒，TikTok 15-60秒
```

**脚本要点：**
- 英文脚本为主，口播风格，避免书面语
- 每条视频末尾植入自然CTA（如"Visit chinapal.world for more"）
- 30-40秒为最佳时长（完播率最高）
- 画面切换节奏：每3-5秒一个镜头

#### 2.2 AI素材图生成

**工具选型：**
- **即梦（Jimeng）**：首选，与剪映生态打通，中文提示词友好
- **Doubao Seedream**：扣子内置生图，适合批量调用
- **Midjourney/Stable Diffusion**：备选，风格化强但需登录

**素材规格：**
- YouTube Shorts / TikTok：1080×1920（9:16竖版）
- Pinterest Pin：1000×1500（2:3竖版）
- 分辨率：72dpi即可，文件大小<500KB/张

**批量生图技巧：**
- 一次生成10-15张，筛选最佳5-8张用于一条视频
- 保持同一prompt风格种子，确保视觉统一性（v3风格）
- 产品图必须1:1匹配实物，禁止变形（关键校验点）
- 人物场景用Ken Burns替代真人出镜

#### 2.3 音频素材

**配音方案：**
- **TTS语音合成**：男声"爽朗少年"风格，适合年轻受众
- **真人录音**：重要视频可用真人配音（成本高，批量不推荐）
- **BGM**：剪映内置版权音乐库，选择节奏匹配画面的

**音频处理：**
- 采样率44100Hz，单声道
- 音量标准化（-16 LUFS）
- 配音+背景音乐分层，BGM音量降至配音的20-30%

### 第三步：视频制作

#### 3.1 Ken Burns动效制作（核心方法）

**原理：** 对静态图片施加缓慢的缩放（Zoom）和平移（Pan）动画，模拟摄像机运动，使静态图产生电影感动态效果。

**参数配置：**
```
Ken Burns动效参数（v3风格）：
├── 缩放：从100%缓慢放大至115-130%（或反向120%→100%）
├── 平移：水平/垂直方向，移动幅度为画面的5-15%
├── 速度：匀速或缓入缓出（ease-in-out）
├── 时长：每张图3-5秒
├── 转场：交叉溶解（crossfade）0.5-1秒
└── 整体节奏：5-8张图 × 4秒 = 20-32秒总时长
```

**即梦/Ken Burns制作流程：**
1. 准备5-8张高质量竖版素材图
2. 使用moviepy脚本批量添加Ken Burns效果：
   - `zoom_factor`：1.0→1.2（慢推）或 1.2→1.0（慢拉）
   - `pan_direction`：left/right/up/down 随机组合
   - `fps`：30fps
3. 叠加配音音频轨
4. 叠加字幕（白色+黑色描边，底部居中）
5. 添加片尾CTA卡片（2-3秒）
6. 导出：H.264编码，1080×1920，30fps

**FFmpeg快速实现：**
```bash
# 单张图Ken Burns效果（zoompan滤镜）
ffmpeg -loop 1 -i input.jpg -vf "zoompan=z='min(zoom+0.0015,1.3)':d=120:x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':s=1080x1920:fps=30" -t 4 -c:v libx264 -pix_fmt yuv420p output.mp4
```

#### 3.2 剪映二次编辑SOP

**标准流程：**
1. **导入素材**：AI生成的图片/视频片段
2. **添加Ken Burns动效**：剪映内置"图片动效"功能
3. **配音对齐**：将TTS音频拖入时间轴，对齐画面节奏
4. **字幕叠加**：
   - 自动识别字幕（剪映AI功能）
   - 手动校对，确保英文拼写正确
   - 字体：无衬线体，白色+黑色描边
5. **BGM添加**：
   - 从剪映版权库选取
   - 音量降至20-30%
6. **转场效果**：
   - 图片间使用"交叉溶解"或"缩放过渡"
   - 避免花哨转场，保持专业感
7. **AI声明**：
   - 片尾添加"AI-generated content"标识（合规要求）
8. **导出设置**：
   - 分辨率：1080×1920
   - 帧率：30fps
   - 编码：H.264
   - 码率：推荐8-12Mbps

#### 3.3 视频风格统一性（v3风格规范）

**v3风格定义：**
- 写实图片+情感TTS配音
- Ken Burns慢推/慢拉动效
- 简洁白色字幕+黑色描边
- 自然CTA收尾，不硬广
- 整体色调偏暖，饱和度适中
- 节奏舒缓但信息密度高

**风格检查清单：**
- [ ] 画面无AI痕迹（手指畸变、文字乱码等）
- [ ] 产品无变形（比例正确、文字清晰）
- [ ] 配音自然流畅，无机械感
- [ ] 字幕与配音同步
- [ ] CTA自然不生硬

### 第四步：多平台适配

#### 4.1 YouTube Shorts

**规格要求：**
- 分辨率：1080×1920（9:16）
- 时长：≤60秒（最佳30-45秒）
- 编码：H.264 + AAC
- 文件大小：≤256MB
- 帧率：30fps

**发布规范：**
- 标题：英文，含关键词，≤100字符
- 描述：2-3行关键词+CTA+链接
- 标签：5-10个相关标签
- 缩略图：自动生成或自定义（1280×720）
- 发布时间：美东时间19:00-21:00（高峰时段）

**内容适配：**
- 片尾加"Link in description"引导
- 评论区置顶放独立站链接
- 加 #Shorts 标签

#### 4.2 TikTok

**规格要求：**
- 分辨率：1080×1920（9:16）
- 时长：15-60秒（最佳15-30秒）
- 编码：H.264 + AAC
- 文件大小：≤287.6MB
- 帧率：30fps

**发布规范：**
- 标题/描述：英文，含话题标签
- 话题标签：3-5个（#vacuumsealer #kitchenhack #ChinaPal）
- 音乐：可用TikTok热门音乐替换（提升曝光）
- 发布时间：美东时间12:00-15:00 或 19:00-22:00

**内容适配：**
- 开头3秒必须有强钩子（TikTok用户耐心更低）
- 可加TikTok原生特效增加平台亲和感
- Bio链接引导至独立站

#### 4.3 Pinterest Video Pin

**规格要求：**
- 视频：分辨率1080×1920（9:16）或 1000×1500（2:3）
- 图片Pin：1000×1500（2:3），竖版优先
- 视频时长：≤15秒（Pinterest偏好短小精悍）
- 文件大小：视频≤100MB，图片≤20MB

**发布规范：**
- 标题：英文，含搜索关键词（Pinterest是视觉搜索引擎）
- 描述：200-500字符，关键词密度高
- Board归属：归入对应主题Board
- 发布频率：每日1-2条（养号期），稳定后5-10条/日

**内容适配：**
- Pinterest用户偏"灵感收集"型，内容偏教程/灵感/美学
- 图片叠加文字标题（Pinterest用户习惯看图不看视频）
- 同一素材拆分为：视频Pin + 静态图Pin + 信息图Pin
- EN站和JP站分别发布（不同语言版本）

#### 4.4 多平台素材复用策略

**一次制作，多平台分发：**
```
原始素材（8张图 + 1条配音）
├── YouTube Shorts版：完整版45-60秒，片尾加CTA卡片
├── TikTok版：精简版15-30秒，快节奏剪辑，换热门BGM
├── Pinterest视频Pin：截取最佳15秒片段
├── Pinterest静态Pin：选最佳1-2张图+文字叠加
└── Instagram Reels版：同TikTok版（可复用）
```

### 第五步：热点快速响应流程

#### 5.1 热点识别
- 每日扫描：TikTok Trending、Google Trends、社媒热搜
- 评估标准：与产品/品牌的关联度 > 热度排名
- 时效窗口：发现后24h内必须出片，否则热点过期

#### 5.2 快速制作流程（赵家驹10条经验）
```
热点快速响应SOP（目标：2小时内出片）：
├── 0-15min：确定选题方向 + 撰写脚本（300字以内）
├── 15-45min：AI批量生成8-10张素材图
├── 45-60min：TTS生成配音 + 筛选最佳音频
├── 60-90min：moviepy/FFmpeg批量合成视频（Ken Burns动效）
├── 90-110min：质量检查 + 微调
└── 110-120min：导出 + 准备发布物料
```

#### 5.3 批量制作成本控制
- **AI生图**：即梦/Seedream，每条视频约¥1-2（8-10张图）
- **TTS配音**：扣子内置，几乎零成本
- **视频合成**：FFmpeg/moviepy脚本，零成本
- **总计**：10条视频成本约¥9（赵家驹项目实测）
- **关键**：优先使用免费/低成本工具，避免高额API调用

### 第六步：质量检查

#### 6.1 质量检查清单

**画面质量：**
- [ ] 产品无变形（比例、文字、Logo不变形）
- [ ] 无AI痕迹（手指畸变、文字乱码、背景异常）
- [ ] 画面分辨率达标（1080×1920）
- [ ] 色彩/风格一致（v3风格统一性）

**音频质量：**
- [ ] 配音清晰，无噪音
- [ ] BGM音量适当（不盖过配音）
- [ ] 配音与画面同步

**字幕质量：**
- [ ] 英文拼写正确
- [ ] 字幕时间轴对齐
- [ ] 字体大小适中，可读性好

**内容质量：**
- [ ] 开头3秒有钩子
- [ ] CTA自然不生硬
- [ ] 时长符合平台要求
- [ ] 无敏感/违规内容

**平台适配：**
- [ ] 分辨率和比例正确
- [ ] 文件大小符合平台限制
- [ ] 编码格式正确（H.264+AAC）
- [ ] 文件可正常播放

#### 6.2 产品无变形校验（铁律）
- 真空机/袋图视频必须1:1匹配实物
- 产品比例、按钮位置、Logo不得变形
- 校验方法：与原图叠放对比，检查边缘是否对齐

### 第七步：发布管理

#### 7.1 发布排期
- **YouTube Shorts**：每周2-3条，美东时间19:00-21:00
- **TikTok**：每周3-5条，美东时间12:00-15:00
- **Pinterest**：每日1-2条（EN站+JP站），全天均可
- **避免同时发布**：各平台间隔2-4小时

#### 7.2 发布物料准备
每条视频发布前准备：
- 视频文件（各平台规格版本）
- 标题（各平台语言版本）
- 描述/文案
- 标签/话题
- 缩略图（YouTube需要）
- CTA链接

#### 7.3 发布后检查
- 确认视频已正常播放
- 检查标题/描述是否正确显示
- 确认链接可点击
- 记录发布时间，用于后续数据分析

## 注意事项

1. **AI视频生成不上传人脸参考图**，仅用纯产品图，规避人脸版权风险
2. **产品图必须1:1匹配实物**，真空机/袋图不得变形
3. **视频不上传人脸**，全用手+产品+操作特写（产品类视频）
4. **AI声明必须添加**，片尾标注"AI-generated content"
5. **英文优先**，目标受众为海外市场
6. **CTA自然植入**，每条视频末尾引导访问独立站
7. **品牌名统一**：对外使用七力/Qili/ChinaPal AI，禁止使用Coze
8. **成本红线**：单条视频成本控制在¥2以内，批量制作走脚本自动化
9. **GeeLark按分钟计费**，发布操作完成立即关机
