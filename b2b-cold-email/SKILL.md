# 外贸B端冷邮件获客技能

## 一、核心铁律（不可违反）

1. **中国邮箱过滤铁律**：所有线索必须过滤中国域名邮箱（@qq.com / @163.com / @126.com / @sina.com / @yeah.net / @sohu.com / @hotmail.* 中国注册 等），确保触达真实海外客户
2. **冷邮件预热铁律**：新域名梯度预热，首日≤10封，周累计≤50封，逐周递增，严禁突然大量发送
3. **背景筛查铁律**：发前必查商标/公司归属，排除中国/香港背景公司，同行竞品不白发（避免免费教对手）
4. **合规群发铁律**：禁无差别群发，仅走合规获客渠道（LinkedIn搜索+B2B平台+海关数据+行业展会名录）
5. **防造假铁律**：每次发送后必须校验已发目录存证，确认实际发出数量与目标一致
6. **B端线索划分铁律**：仅保留批发商/分销商/跨境卖家/小B线索，纯C端消费者转独立站处理，不占B端资源
7. **零手动铁律**：全流程自动化执行，禁止要求用户手动操作（注册/配置/验证等一律自动化）

## 二、全流程执行步骤

### Phase 1：线索库建设

**目标**：建立分层线索库，按质量分Tier1/2/3

#### Step 1.1 LinkedIn决策人搜索
```
搜索策略：
1. 关键词组合：产品词 + buyer/procurement/purchasing/director/owner/founder
2. 地区筛选：目标市场国家
3. 公司规模：11-50人 / 51-200人（中小批发商主力区间）
4. 行业筛选：对应产品行业

预热流程（新号必做）：
- 第1-3天：仅加同行/朋友，不搜索不发消息
- 第4-7天：每天访问10-15个profile，点赞同行帖子
- 第8天起：开始搜索决策人，每天访问20-30个profile
- 禁止一天内大量访问陌生profile，触发风控
```

#### Step 1.2 多源线索获取
```
来源优先级：
1. LinkedIn搜索结果（质量最高，决策人直达）
2. 海关数据平台（ImportYeti/Panjiva）— 真实进口商
3. Instagram B2B搜索 — 批发商/分销商
4. Google搜索 — 目标市场+产品+wholesale/distributor
5. 行业展会参展商名录
6. B2B平台（Alibaba竞品店铺买家、Global Sources）

每条线索必须记录：
- 公司名、国家、联系人姓名、职位
- 邮箱（必须验证格式）
- 来源渠道、获取日期
- 初步分级：Tier1（明确批发需求）/ Tier2（潜在B端）/ Tier3（需进一步验证）
```

#### Step 1.3 线索清洗与验证
```
清洗规则：
1. 去重：按公司名+域名去重
2. 中国/香港背景排除：查官网、查商标归属、查注册地址
3. 同行排除：搜索公司名+竞品品牌名，确认非同行
4. 邮箱格式验证：检查@域名是否为该国本地域名
5. C端过滤：个人Gmail/Outlook占主导且无公司官网的排除

验证工具：
- Hunter.io（邮箱格式推测）
- NeverBounce / ZeroBounce（邮箱有效性验证）
- 域名WHOIS查询（确认公司归属）
```

### Phase 2：邮件撰写

#### Step 2.1 邮件模板设计
```
模板原则：
1. 标题简短直接，不含营销词（避免"best price""free sample"等触发SPAM）
2. 正文3-5段，≤150词
3. 第一段：点明来意+对方公司名（个性化）
4. 第二段：核心价值主张（工厂直供/MOQ灵活/品质认证）
5. 第三段：CTA（简单一个问题，如"是否方便安排10分钟通话？"）
6. 签名：真实姓名+职位+公司+WhatsApp/Telegram

多语言版本：
- 英语（全球通用版）
- 俄语（俄罗斯/独联体市场）
- 西班牙语（拉美市场）
- 阿拉伯语（中东市场）
- 日语（日本市场）

A/B测试变量：
- 标题风格：直接型 vs 问题型
- CTA风格：通话邀请 vs 目录发送 vs 样品邀请
- 长度：精简版 vs 详细版
```

#### Step 2.2 邮件内容规范
```
禁止内容：
- 大写字母全标题
- 过多感叹号
- "100% free""no cost"等绝对化用语
- 附件PDF（首轮不带附件，降低SPAM分）
- 过多链接（≤1个，放官网链接即可）
- 图片签名（触发HTML过滤）

推荐内容：
- 纯文本格式（SPAM分最低）
- 个性化变量（{{company_name}} {{first_name}}）
- 一个明确的CTA
- 退订提示（合规要求）
```

### Phase 3：域名预热与发送策略

#### Step 3.1 新域名预热流程
```
预热周期：2-4周
阶梯计划：
  第1周：Day1≤10封，Day2-3各10封，Day4-5各15封 → 周累计≤50封
  第2周：每天15-20封 → 周累计≤100封
  第3周：每天20-25封 → 周累计≤150封
  第4周：每天25-30封 → 周累计≤180封

注意事项：
- 工作日发送，周末不发（B端邮件周末送达率极低）
- 发送时间：目标时区上午9-11点（收件人上班查看邮件高峰）
- 同一域名每天发送量不超过前一天的120%
- 退信率>5%立即暂停，排查原因
```

#### Step 3.2 双通道并行策略
```
通道配置：
- 主通道：Zoho Mail SMTP（企业邮箱，信誉度高）
- 备用通道：Gmail SMTP（补充发送量）
- 两通道按地区/批次交替使用，避免单点风险

发送节奏：
- 每批次20-25封
- 批次间隔≥2小时
- 每天最多3个批次
- 每封之间随机延迟30-120秒
```

### Phase 4：批量发送执行

#### Step 4.1 发送脚本架构
```python
# 核心发送流程伪代码
1. 读取待发送队列（按Tier排序：Tier1优先）
2. 逐条执行：
   a. 背景复查（公司名搜索，确认非中港背景/非同行）
   b. 邮箱格式最终校验
   c. 模板渲染（替换个性化变量）
   d. 通过SMTP发送
   e. 记录到已发日志（时间/收件人/主题/通道/状态）
   f. 随机延迟30-120秒
3. 批次完成后校验：
   a. 统计实际发送数 vs 计划数
   b. 检查退信列表
   c. 更新无效邮箱黑名单
   d. 写入发送存证
```

#### Step 4.2 VPS发送环境
```
部署位置：US VPS（美国IP，邮件信誉度高）
环境要求：
- Python 3.8+
- SMTP凭据加密存储
- 发送日志实时写入JSON
- 退信自动归类

发送后存证校验（防造假铁律执行）：
- 对比发送脚本日志 vs SMTP实际投递记录
- 确认每封邮件的Message-ID
- 存证文件命名：sent_log_YYYYMMDD_waveN.json
```

### Phase 5：跟进管理

#### Step 5.1 回复监控
```
监控频率：每天检查2次（上午/下午各一次）
分类处理：
- 正面回复（有兴趣/要报价）→ 24小时内回复，转人工确认
- 中性回复（询问更多细节）→ 发送产品目录+报价单
- 拒绝回复 → 标记，不再跟进
- 退信/自动回复 → 更新黑名单/状态
- 超7天无回复 → 发送第一次跟进邮件
- 超14天无回复 → 发送第二次跟进邮件（换角度/提供新信息）
- 超21天无回复 → 标记为冷线索，转入长期培育
```

#### Step 5.2 跟进邮件策略
```
跟进节奏：
- Follow-up 1（+7天）：简短提醒+补充一个卖点
- Follow-up 2（+14天）：提供市场数据/案例/样品邀请
- Follow-up 3（+21天）：最终跟进，"如有需要随时联系"
- 超过3次无回复 → 停止跟进，避免被标记SPAM

跟进邮件注意：
- 不要重复第一封的内容
- 每次提供新价值（新品/市场趋势/限时信息）
- 保持简短
```

## 四、关键指标与复盘

### 核心KPI
```
- 线索有效率：清洗后有效线索 / 原始线索 ≥ 60%
- 送达率：成功送达 / 发送总量 ≥ 90%
- 打开率：≥ 30%（低于20%需优化标题）
- 回复率：≥ 3%（冷邮件行业基准1-5%）
- 询盘转化率：回复 → 真实询盘 ≥ 30%
- 退信率：< 5%（超过立即暂停排查）
```

### 复盘周期
```
- 每日：检查退信、更新黑名单
- 每周：统计发送量/回复率/新线索数
- 每两周：A/B测试结果分析，优化模板
- 每月：整体漏斗复盘，调整策略
```

## 五、常见问题与解决方案

### Q1：邮件全进SPAM怎么办？
```
排查清单：
1. 检查域名SPF/DKIM/DMARC记录是否配置正确
2. 检查发送量是否超过预热节奏
3. 检查邮件内容是否含SPAM触发词
4. 检查发送IP是否在黑名单（mxtoolbox查询）
5. 切换发送通道/域名
```

### Q2：退信率突然飙升？
```
处理步骤：
1. 立即暂停发送
2. 分析退信原因（硬退信=邮箱不存在 / 软退信=邮箱满/临时拒绝）
3. 硬退信地址加入黑名单
4. 检查线索来源是否可靠
5. 重新验证剩余邮箱
6. 退信率降至<3%后恢复发送
```

### Q3：零回复怎么办？
```
排查顺序：
1. 确认邮件是否真正送达（非SPAM）
2. 检查邮件内容是否有吸引力
3. 检查目标客户是否精准（是否真为B端决策人）
4. 检查发送时间是否在目标时区工作时间
5. 考虑换模板/换CTA/换标题
6. B2B冷邮件通常需要7-14天才会有首批回复，不要过早下结论
```

### Q4：如何判断客户是否中港背景？
```
筛查方法：
1. Google搜索公司名+"China" OR "Hong Kong" OR "深圳" OR "香港"
2. WHOIS查询官网注册信息
3. 检查官网是否有中文版
4. 查LinkedIn上员工构成
5. 查商标注册归属（USPTO/EUIPO/WIPO）
6. 检查域名注册日期和注册商
```

### Q5：多语言邮件注意事项？
```
关键要点：
- 不要用Google翻译直出，至少人工校对
- 俄语/阿拉伯语/日语格式差异大（称谓、敬语）
- 邮件编码必须UTF-8
- 部分国家偏好本地邮箱（如俄罗斯常用Mail.ru/Yandex）
- 首轮邮件建议用英语（通用性最强），确认对方偏好后再切换
```
