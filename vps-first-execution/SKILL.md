# vps-first-execution：执行类任务一律走 VPS 通道

> 袁总令（2026-10-25）：所有需要网络、设备、持久化的执行任务，走 VPS 通道，不用本地沙箱执行。本技能为全项目公共层，新项目/新规划开机先读本库即继承。

## 原则
- **沙箱** = 一次性草稿间：只做文本处理、代码编写、git 操作；断即弃，不留密钥、不跑服务、不做长任务
- **VPS** = 唯一执行地面：一切对外操作（发帖、发信、API 调用、设备/云手机、定时任务、数据抓取）都在 VPS 上跑

## VPS 通道（凭证明文不入库，一律从 ai-sync 总线 CRED/GRANT 信读取）
1. 命令执行：`POST https://aihubai.cn/vps-api/api/exec`（Bearer 令牌 → 总线信件）
2. 任务下发：ai-sync 仓库 `inbox/task_<描述>_<序号>.md` → dispatcher 每分钟执行，结果在 `done/`、`failed/`
3. 云手机/设备：GeeLark OpenAPI（令牌同走总线信件；只碰指定设备，用完即关机省费）
4. VPS 侧项目资产目录：`/root/projects/<项目名>/`

## 铁律
- 产出双备份：VPS + git 仓库；沙箱只当草稿
- 任务第一次失败后先回本技能库/ai-skills 查坑，不重复踩
- 密钥三不：不进仓库、不进聊天、不进记忆（只存总线私有信件/袁总项目指令）
