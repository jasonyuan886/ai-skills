# plan-feedback-loop：计划-执行-反馈-完结闭环

> 袁总令（2026-10-27）：任何项目组做完计划，必须立即建立实施结果反馈机制和任务完结机制。本技能为全项目公共层，新项目开机先读即继承。
> 标准件：ai-sync 仓库 docs/TASK_PROTOCOL.md + tasks/templates/TASK_CARD_TEMPLATE.md

## 三件套（缺一不可）
1. **立项即建卡**：计划落地 5 分钟内在 tasks/pending/ 建任务卡——目标/步骤/执行方/截止/验收标准（证据形式）/反馈节奏
2. **执行留痕**：步骤级当日更新进度行（时间+结果+证据）；阻塞立即上报不等到死线；项目级 48h 状态条
3. **完结回执**：任务卡移 tasks/done + 完结报告（结果 vs 计划偏差/证据）+ 经验一条回写 ai-skills

## 无声升级
- 截止前 4h 无更新 → 🟡 总管催办
- 截止后 24h 无回音 → 🔴 换人/换路线/上报袁总

## 总管侧
CONTROL_BOARD 在办任务栏每日对照 tasks/pending ↔ done 巡检；任务卡超 48h 无更新列催办区。
