# SKILL-first-on-failure（元技能：先查技能库，再干活）

> 袁总 2026-10-20 机制令，全组织所有 AI 适用。

## 规则
1. **任何任务第一次失败后**，停下——先查 `github.com/jasonyuan886/ai-skills` 技能库（按关键词搜目录，读对应 SKILL.md）
2. 有现成技能 → 照做，不重复踩坑
3. 技能库无解 → 自主探索，**成功后把新方法回写成技能**（同目录结构：适用/步骤/红线/验证/案例）
4. 第二次失败还查不到 → 才允许升级问人/换路线

## 为什么
组织踩过的坑只值一次钱。第一次失败是学费，第二次同样的失败是浪费——技能库就是让每个 AI 站在全组织的经验上干活，而不是各自从零交学费。
